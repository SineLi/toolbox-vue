## Quick start

Click the upload area or drag `.spd` files onto the page. After processing, the SPD spectra will be converted to `.csv` files and downloaded automatically.

### Settings
**Zip download**: Download multiple selected files as a single zip package (bundled in-browser to avoid many separate downloads).

**Auto download**: Convert and download immediately after upload.

*Note: zip download and auto download cannot be enabled at the same time.*

## Notes
This tool currently only supports SPD spectrum files saved by **UVWIN 5.0**. Other formats or file types cannot be processed correctly.
